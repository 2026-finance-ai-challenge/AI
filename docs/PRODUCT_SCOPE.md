# AI 제품 범위

## 역할

Backend가 검증·최소화한 데이터만 받아 OpenAI Responses API로 영어 번역·요약·설명·답변을 생성한다. AI 서비스는 브라우저에 직접 노출하지 않으며 시장·사용자 영속 상태와 인증은 Backend가 관리한다.

## 구현 기능

| 영역 | 입력 | 검증 출력 |
| --- | --- | --- |
| 뉴스 | 원문, 관련 종목, 출처 메타데이터 | 번역, What/Why/Impact, 이벤트, 감성, 중요도, 시장영향, confidence |
| 금융 용어 | 선택 문장, 기사 문맥, 검증 근거 | 영문 정의, 문맥 해설, 근거, confidence |
| 공시 요약 | 고정된 접수번호·문서 버전의 문단·표 | What/Why/Impact와 문단·표 인용 |
| 공시 RAG | 공시별 HALFVEC 검색 근거 | 영어 답변, 주장별 인용, 근거 부족 상태 |
| 시장 Agent | Backend가 조회한 시세·뉴스·공시·세무 문맥 | 출처·기준 시각이 연결된 안내 답변 |
| 세무 OCR | 복호화된 허용 문서 바이트와 기대 문서 유형 | 필드, 누락, 문서 간 불일치, 위험도, 검증 상태 |
| 글로벌 피어 | 검증된 사업·산업·재무 참고 카탈로그 | 대표 피어, 3개 비교 차원, 4개 강점, 근거·confidence |

## 운영 원칙

- OpenAI 호출은 `store=false`를 기본값으로 한다.
- 모델 ID와 프롬프트 버전은 환경 설정으로 주입하고 모든 응답 메타데이터에 기록한다.
- 구조화 결과는 Pydantic/JSON Schema의 필드 수·열거형·인용 형식까지 검증한다.
- 뉴스·공시·사용자 텍스트는 명령이 아닌 신뢰할 수 없는 데이터 경계 안에 넣는다.
- 현재가, 거래 상태, 외국인 한도와 같은 최신 사실은 Backend 도구 결과 없이는 생성하지 않는다.
- 공시 검색 범위는 접수번호·문서 버전으로 격리하고 검색 근거가 부족하면 답변을 거절한다.
- 직접 식별자를 전달하지 않으며 Backend 전용 Bearer 토큰, 허용 호스트, 타임아웃과 제한된 재시도를 적용한다.
- 검증된 피어 참고 데이터가 없는 종목은 임의 결과를 만들지 않는다.

## 서비스 구성

- API 프로세스: 뉴스·요약·답변·OCR·피어의 동기 생성 요청 처리
- RAG 작업자: 공시 payload 청킹·임베딩·작업 큐 처리
- PostgreSQL: 구조화 payload, 검색 위치, HALFVEC, 작업 상태
- OpenAI: Responses API 기반 생성형 분석

## 완료 기준

- 각 생성 기능의 정상·타임아웃·스키마 실패·근거 부족 경로를 테스트한다.
- 정적 분석, 타입 검사와 전체 테스트를 통과한다.
- Backend와 같은 서비스 토큰으로 실행한 Docker 헬스체크를 통과한다.
