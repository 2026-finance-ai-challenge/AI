# 제품 범위

## 목표

MSCI 관련 정보 비대칭과 외국인 투자 장벽을 줄이기 위해 핵심 한국 상장기업 공시를 조회하고, 공시 근거가 표시된 영어 질의응답을 제공한다.

지원 대상은 MSCI Korea 참고군, 시가총액 상위 50개, 외국인 보유 한도 적용 종목을 합친 KOSPI·KOSDAQ 보통주 75개다. 정확한 목록과 기준일은 README에서 관리한다.

## 기능

### 공시 목록

- OpenDART 신규 공시의 주기적 수집
- 지원 종목의 1999년 이후 전 기간 공시 적재
- 종목별 원문 ZIP 보관과 SHA-256 검증 카탈로그
- 전체 기간 전문 Zstandard 압축 보관과 메타데이터 임베딩
- 최근 1년 전체 공시와 최근 5년 사업·반기·분기보고서 청크 사전 색인
- 그 외 공시의 온디맨드 청크 색인
- 현재 공시 청크의 본문 비중복 저장과 공시별 범위 검색
- DB 60GiB 원문 수집 상한과 52GiB RAG 색인 상한
- 우선주·SPAC·ETF·ETN·리츠·DR 제외
- 3개월 단위 체크포인트 기반 중단 재개
- 종목·기간·공시 유형별 필터
- 접수번호, 회사명, 보고서명, 접수일자, 제출인, 정정 여부 제공
- 중복 수집 방지와 최종 수집 시각 제공

### 공시 상세

- 공시 메타데이터, 구조화된 본문, 원문 링크 제공
- 목차, 문단, 표 구조 보존
- 정정공시 버전 연결과 원문 해시 저장

### 공시 RAG 챗봇

- 선택한 공시 범위의 영어 질의응답
- 선택 문단과 인접 문맥 우선 검색
- 회사·공시 유형·접수번호·문서 버전별 검색 범위 제한
- 답변마다 근거 공시 문단 또는 표 제시
- 근거 부족 시 답변 거절

## 서비스 역할

- Backend: OpenDART 수집, 공시 저장, 목록·상세 API, AI 서비스 호출
- AI: 공시 청킹, 임베딩, 벡터 검색, 답변과 인용 생성
- PostgreSQL: 공시 메타데이터, 버전, 청크, 임베딩 저장

## 현재 구현 상태

- 지원 종목 75개의 공시 목록·상세·원문 수집 API 구현
- 공시별 질문, 선택 문단 우선 검색, 인용 및 근거 부족 거절 구현
- Backend와 AI 사이 Bearer 서비스 토큰 인증 구현
- AI API 서버와 RAG 색인 작업자는 독립 프로세스로 실행
- 사용자용 웹 화면은 별도 구현 대상

## 완료 조건

- 신규 공시의 중복 없는 저장 및 목록 반영
- 공시 원문과 정정 버전 추적
- 답변과 실제 공시 근거 연결
- 근거 없는 질문의 명시적 거절
- 수집·조회·검색·답변 실패 경로 테스트
